# Persian AI Assistant Telegram Bot

ربات تلگرام فارسی با حافظه‌ی گفتگو (Supabase) و مدل از OpenRouter.

## متغیرهای محیطی
- `token_bot`: توکن BotFather
- `OPENROUTER_API_KEY`: کلید OpenRouter
- `SUPABASE_URL`: آدرس پروژه‌ی Supabase
- `SUPABASE_KEY`: کلید سرور (service_role)

## اجرای محلی
pip install -r requirements.txt
python bot.py

## دستورها
/start، /help، /about، /clear، /recap
